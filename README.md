# portfolio

A dark, cinematic scientific showcase of computational molecular work: interactive 3D structures,
real DFT and MD data, and de novo design results. Built as a single static page for GitHub Pages.

## Serve

This is a static site. `index.html` is self-contained apart from two CDN scripts (3Dmol.js and Google
Fonts). To publish with GitHub Pages: push this repo, then enable Pages on the default branch, root.

## What it shows

- White-light emitter design space (TD-DFT), with interactive 3D molecules
- MOF organic linker space (DFT), with interactive 3D linkers
- De novo metalloenzyme designs: two structures, a design-landscape scatter, and the full scorecard
- A reference nanocage architecture, with the platform's real specifications
- Metal-site quantum chemistry and validation metrics
- A project index linking to each repository

Every value is computational and drawn from the project's own outputs. Private design IP, client data,
and cluster details are deliberately excluded.
